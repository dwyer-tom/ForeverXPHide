# Changelog

## 1.1.0

- Save the hide/show preference in `ForeverXPHideDB`.
- Default to hiding the XP bar on first install.
- Re-hide the frame when its `OnShow` script runs.
- Retry initialisation after login while the tracking bar becomes available.
- Add `/xphide` and `/fxphide` slash commands.

## 1.0.0

- Initial proof of concept using the WoW Forever Camelot tracking-bar frame hierarchy.
- Hide the XP bar without hiding the overall tracking-bar manager.
